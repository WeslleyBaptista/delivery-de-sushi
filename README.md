# delivery-de-sushi
Este é um projeto de uma loja de delivery de sushi feito com React, focado em uma experiência moderna e eficiente para o usuário.

Tecnologias usadas:

- React
- TypeScript (TS)
- Tailwind CSS
- Zod (validação de schemas)
- React Hook Form (manipulação e validação de formulários)
- Shadcn UI (componentes UI reutilizáveis)
- Hooks personalizados do React
 
 Objetivo:

 Praticar e aplicar conceitos do React, como componentes, props, estados, validação de formulários com Zod e React Hook Form, além da construção de uma interface estilizada e responsiva usando Tailwind CSS e Shadcn UI. O projeto simula um sistema completo de cardápio e carrinho para delivery.


 Como executar:

1. Clone o repositório
2. Rode `npm install`
3. Execute `npm run dev`
